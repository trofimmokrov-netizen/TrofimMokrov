# Результаты проверки прототипа

18 октября 2026 года. Отдельное локальное приложение, не публичная веб-служба.

- 17 автоматических тестов прошли: CSV и дедупликация; ручное подтверждение; обязательность email; снятие одобрения после правок; одна отправка на адрес; блокировка; различение отказа и неизвестного исхода; отсутствие SMTP не расходует одобрение; блокировка внутренних URL; контракт ответа Яндекса; HTTP API; защита от чужого Origin и отсутствующего токена; dry-run очереди; отправка только одобренных записей с паузой; остановка очереди при неизвестном исходе.
- Браузерный сценарий прошёл: CSV → карточка → подтверждение → черновик → одобрение → изменение текста → сохранение → «Не писать».
- Интерфейс проверен на 320, 390, 768, 1440 px. Ошибок JavaScript и горизонтального переполнения не обнаружено.
- При отсутствии SMTP кнопка отправки отключена. Несохранённые изменения не могут быть отправлены как будто они одобрены.
- Приложение запущено на loopback с отдельной временной тестовой базой. Тестовые компании и контакты вымышлены; они не входят в поставляемую базу и не закоммичены.
- База, .env, файлы Python cache исключены из Git. Backend не раздаёт файл SQLite.
- Основной сайт: проверка 13 HTML-страниц прошла; его структура не изменялась.

## Что не проверено вживую

Ключ Яндекса отсутствует, официальная документация недоступна из среды (403 прокси). API-адаптер проверен на тестовом ответе, не на реальном аккаунте. Условия тарифа, хранения данных и географический охват нужно проверить перед реальным использованием.

SMTP не настроен: отправка проверялась подставными обработчиками, не через Gmail. Ни одного реального письма не отправлено. Требуются учётные данные отправителя и TCP-доступ к почтовому серверу.

Глобального поиска email по интернету, проверки ответов, обработки отказов из входящей почты, отслеживания открытия, языковой модели для персонализации и глобального источника всех организаций в этой версии нет. Доступен проверенный локальный цикл работы с импортированной базой, а внешние подключения требуют завершения настройки.

Наблюдение текущей среды: в /etc/codex/network-policy.json список TCP-доменов и диапазонов пуст. Прямой доступ к SMTP Gmail не подтверждён и не должен предполагаться доступным. Для живой отправки используйте компьютер/сервер с разрешённым SMTP либо отдельно настройте поддерживаемый TCP-доступ.

## Обновление: открытый поиск и разбор сайтов

24 автоматических теста прошли (17 прежних и 7 новых). Проверены извлечение mailto и видимого текста, игнорирование скриптов, ссылки на контакты только своего домена, сохранение URL источника, лимит трёх страниц, запрет robots.txt, остановка при robots 403, разбор ответа OSM и отказ от запроса на весь мир. Доказано отсутствие автоматического одобрения и перезаписи email при разборе сайта.

Live-запрос Overpass блокируется HTTPS-прокси (403). Реальные компании не получены, обработка настоящих сайтов в текущей среде не подтверждена. Новые тесты используют сохранённые ответы/HTML и не отправляют письма.
