# Трофим Мокров — персональный сайт

Статический многостраничный сайт: HTML, CSS, JavaScript. Сборка — стандартная библиотека Python 3, без npm, базы данных и сервера приложения. Сгенерированные HTML уже находятся в репозитории и работают без JavaScript; JavaScript добавляет меню и необязательные анимации.

## Запуск и сборка

```sh
cd /workspace/TrofimMokrov
python3 scripts/build.py
python3 -m http.server 8000 --bind 127.0.0.1
```

Проверьте страницы локальным HTTP-запросом или браузером. Не создавайте дополнительный worktree для обычной задачи: используйте имеющуюся изолированную копию.

## Редактирование

- `content/site.json` — имя, контакты и подтверждённый публичный URL.
- `content/services.json` — состав и цены. Сохраняйте уникальный `id` из латиницы, цифр и дефисов.
- `content/projects.json` — портфолио. Отдельно указывайте задачу, вклад и проверенный результат. `watermark: true` добавляет подпись «Трофим Мокров» поверх изображения, не меняя оригинал. Не используйте watermark для чужих материалов. Изображение необязательно: можно описать подтверждённый проект без него.
- `content/articles/*.json` — отдельная статья: уникальный `slug`, категория, заголовок, описание, секции и `service` (id связанной услуги). Создайте копию существующего файла, измените данные и пересоберите сайт.
- `assets/styles.css` и `assets/main.js` — оформление и поведение.
- `scripts/build.py` — шаблоны и генерация страниц.

После изменения данных выполните `python3 scripts/build.py` и сохраните и исходные данные, и обновлённый HTML. Генератор не обращается к сети. Не редактируйте только сгенерированный HTML: последующая сборка заменит его.

Для нового изображения сохраните собственный оригинал отдельно, подготовьте публичную копию без личных данных, задайте путь и содержательный `alt` в проекте. Для большого портфолио используйте разумные размеры публичных копий и современные форматы; не загружайте оригиналы многомегапиксельных фотографий в каждую карточку. Текущая иллюстрация локальная; для страницы используется WebP без потери качества (991 176 байт вместо 1 734 958 байт исходного PNG). Исходный PNG сохранён. Внешних шрифтов и изображений нет.

## Размещение в GitHub Pages

Адрес `https://trofimmokrov-netizen.github.io/TrofimMokrov/` предоставлен пользователем на скриншоте и записан в base_url. Прямой внешний запрос из среды блокируется прокси, поэтому актуальное состояние публикации здесь не подтверждено. Сайт совместим с project Pages, есть `.nojekyll` и прямые адреса страниц.

1. В GitHub откройте Settings → Pages репозитория.
2. Выберите Deploy from a branch → `main` → `/ (root)` → Save.
3. Дождитесь успешной публикации и возьмите реальный адрес из Pages. Не угадывайте домен.
4. Укажите этот адрес без завершающего слеша в `base_url` файла `content/site.json`.
5. Пересоберите сайт, закоммитьте и отправьте изменения. Генератор добавит canonical, полный адрес Open Graph-изображения, sitemap.xml и robots.txt.
6. Проверьте главную, прямую ссылку на статью, стили и 404 по публичному адресу.

При пустом `base_url` отсутствуют фиктивные canonical и sitemap. Предпросмотр Open Graph без подтверждённого абсолютного адреса изображения ограничен. В проекте нет отправки форм, аналитики, cookies и сторонних виджетов. Контакты открывают реальные приложения/сервисы.

## Проверки и документы

`python3 scripts/check.py` проверяет HTML, локальные пути, метаданные, уникальность идентификаторов и ссылки. Браузерные проверки: при наличии Playwright и Chromium выполните `CHROMIUM_PATH=/usr/bin/chromium node scripts/browser-check.cjs`. Для управляемого браузера Playwright опустите CHROMIUM_PATH. Сервер должен работать; другой адрес задаётся переменной SITE_URL. Флаг `--capture` обновляет собственный скриншот в портфолио. Подробности результатов — в `docs/VALIDATION.md`.

- `docs/PRICING.md` — предварительная сетка, модель трудозатрат и ограничения исследования.
- `docs/CONTENT-AUDIT.md` — что подтверждено и какие материалы ещё нужны.

## Анимация текста

Заголовки раскрываются по словам при первом попадании в экран. На главной три короткие фразы сменяются с паузой 5,2 секунды. Кнопка «Пауза» останавливает смену; скрытая вкладка или блок вне экрана также её приостанавливают. `prefers-reduced-motion` отключает движение, в том числе при изменении настройки во время просмотра. Без JavaScript остаются обычные заголовки и первая фраза. Текст статей не анимируется при чтении.

Проверка движения: `CHROMIUM_PATH=/usr/bin/chromium node scripts/motion-check.cjs` при запущенном локальном сервере и доступном Playwright.

## Предпросмотр ссылки

Заголовок и описание берутся из метаданных генератора. Изображение `assets/share-card.png` имеет размер 1200 × 630; его исходный макет — `scripts/share-card.html`. Open Graph использует абсолютный URL. После публикации Telegram может показывать сохранённую карточку: повторное размещение ссылки с новым параметром (например, `?v=2`) может запросить свежий предпросмотр. Обновление кэша Telegram этим репозиторием не управляется.

## Telegram-бот для входящих заявок

Кнопки «Оставить заявку в боте» открывают `@TrofimAI_bot`; выбранная услуга передаётся из карточки. Личная связь с `@TrofimMokrov` сохранена. Серверная часть меню и заявок находится в `telegram_bot/`: отдельный Python-процесс, SQLite вне публичного сайта и секретный токен в настройках процесса. Подготовленный код требует запуска и проверки реальной доставки; GitHub Pages его не выполняет. Настройки, команды и ограничения — в [telegram_bot/README.md](telegram_bot/README.md).

## Отдельный инструмент поиска клиентов

В `leadfinder/` находится отдельная локальная панель: база компаний, импорт CSV, адаптер поиска организаций Яндекса, проверка сайтов, подготовка и одобрение писем, SMTP и ограниченная очередь. Запуск: `python3 leadfinder/server.py`. Это backend-приложение, GitHub Pages его не запускает. Реальные подключения Яндекса и почты требуют ключа и почтовых настроек. Подробности — в [leadfinder/README.md](leadfinder/README.md).

## Мини-приложение Telegram

В `miniapp/` — каталог и форма заявки внутри Telegram. В `@TrofimAI_bot` отправьте `/menu` и выберите «Открыть приложение». Каталог общий с сайтом, бот проверяет и сохраняет заявку, затем уведомляет владельца. Для кнопки нужен опубликованный HTTPS-адрес `TELEGRAM_MINIAPP_URL`; подробности и проверки — в [miniapp/README.md](miniapp/README.md).
