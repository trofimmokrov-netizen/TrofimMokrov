# Личные публикации TrofimAI

Редактор доступен только `TELEGRAM_OWNER_CHAT_ID` в личном чате. Посетители не
получают доступ к черновикам, аккаунтам и отправке. Тарифы и платежи в эту версию
не входят. Она поддерживает сайт и до трёх профессиональных Instagram-аккаунтов.

## Использование

1. `/publish` или кнопка «Мои публикации» в меню владельца.
2. Готовый текст до 2200 символов. Первая строка — заголовок на сайте.
   При подключённом OpenAI API можно написать `Идея: описание будущего поста`.
   AI возвращает черновик; проверьте факты перед отправкой.
3. Одно фото, отправленное обычной фотографией Telegram, или «Без фотографии».
   Для Instagram нужен JPEG до 8 МБ с пропорциями 4:5–1.91:1. Кадрирование
   выполняется до отправки. Видео, альбомы, Stories и Reels пока не поддерживаются.
4. Выберите одну или несколько площадок. Повторное нажатие снимает выбор.
5. «Предпросмотр» → «Подтвердить публикацию». До подтверждения публичной записи нет.
   Можно изменить текст, выбрать другие площадки или отменить черновик.
6. Бот отдельно сообщает подтверждённый результат каждой площадки. `/publications`
   показывает последние отправки, `/accounts` — состояние настройки площадок.

## Instagram: первый аккаунт

Используется **Instagram API with Instagram Login**, адрес `graph.instagram.com`.
Токены от Facebook Login и идентификаторы страниц Facebook сюда не подходят.

В Meta for Developers создайте приложение с Instagram API, добавьте свой
профессиональный Business/Creator аккаунт и выдайте разрешения
`instagram_business_basic` и `instagram_business_content_publish`. Для личного
тестирования аккаунт должен иметь соответствующую роль/приглашение в приложении.
Для доступа посторонних клиентов понадобится отдельный OAuth-процесс,
рассмотрение разрешений Meta и пользовательское хранение подключений.

Сохраните токен **в защищённых настройках среды** как `INSTAGRAM_1_TOKEN`.
Не отправляйте его в чат и не добавляйте в Git. Срок действия и продление токена
контролирует владелец; автоматическое OAuth-продление ещё не реализовано.

`TROFIM_PUBLISH_ACCOUNTS` указывает на JSON-файл **вне публичного репозитория**:

```json
[
  {"slot": 1, "username": "zavodclauda", "user_id": ""}
]
```

В этой среде подготовлен `/workspace/.trofimai/instagram-accounts.json`.
`user_id` можно оставить пустым: он определяется через `/me` и проверяется
вместе с username до отправки. При заданном ID он также должен совпасть.
Для второго/третьего аккаунта добавьте записи со слотами 2/3 и отдельные
защищённые `INSTAGRAM_2_TOKEN` / `INSTAGRAM_3_TOKEN`, затем перезапустите процесс.
Нельзя использовать один слот дважды. `/accounts` показывает настройку, а не
доказательство действительности токена: разрешения проверяются при отправке.

Версия Graph API задаётся `INSTAGRAM_GRAPH_VERSION`, по умолчанию `v24.0`.
При изменении требований Meta сверяйте версию и разрешения с её документацией.
Реальные вызовы Instagram не проверены без выданного доступа.

## AI-текст

Опциональная защищённая переменная `TROFIM_OPENAI_TOKEN` — ключ OpenAI API.
Подписка ChatGPT его не заменяет. Используется Responses API, `store: false`,
модель `gpt-4.1-mini` или значение `TROFIM_TEXT_MODEL`. Оплата — по тарифам API.
В OpenAI передаётся только введённая идея; фото и база клиентских заявок не
передаются. Без ключа доступна публикация готового текста. Черновики остаются
в приватной SQLite-базе до ручной очистки.

## Сайт, хранение и запуск

Сайт публикуется через GitHub Pages. У процесса должен быть HTTPS Git-доступ
на запись к `origin`, ветка `main`. В приватном каталоге рядом с SQLite создаётся
отдельная копия `site-publisher`; основной рабочий checkout не переключается.
Для постоянного сервера отдельно настройте Git-аутентификацию с правом записи
только в этот репозиторий. Доступ Codex через платформенный прокси не означает,
что он автоматически появится на другом сервере.

Подтверждённые заметки записываются в `content/updates/<id>.json`, фотографии —
`assets/updates/<id>.jpg`; генератор собирает `updates.html`. Сначала выполняются
сборка и проверка ссылок, затем коммит и push. Бот ждёт появления записи и фото
на публичном сайте; подтверждение Git push само по себе не считается публикацией.
Если выбран только Instagram, фото всё равно размещается публично на сайте,
поскольку Instagram должен скачать его по HTTPS. Фотографии не удаляются
автоматически. Черновики, токены и заявки в публичный checkout не попадают.

Необходимые адреса: `api.telegram.org`, `graph.instagram.com`, `api.openai.com`
(для AI), GitHub HTTPS origin и домен GitHub Pages сайта. Сохраняйте прокси
и проверку TLS. Один worker: `python3 -m telegram_bot.run --db <приватная SQLite>`.
Нужны `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_CHAT_ID`, `TROFIM_PUBLISH_ACCOUNTS`
и, при использовании Mini App, `TELEGRAM_MINIAPP_URL`. Базу храните вне checkout.
Секреты и конфигурация читаются при старте; после их изменения процесс перезапускают.

Служба должна работать на сервере с постоянным диском и автоматическим запуском.
Фоновый процесс в облачной задаче не гарантирует работу после остановки машины.
Планирование по времени, массовые публикации, платные кабинеты и автоматическое
продление Meta-доступа в эту первую версию не входят.

## Ошибки и защита от дублей

SQLite хранит подтверждённую очередь и результаты независимо по площадкам.
Instagram: контейнер создаётся отдельно, его готовность проверяется перед
публикацией. При потере ответа на `media_publish` результат — `unknown`,
автоматического повторения нет. После аварии во время отправки бот также
предупреждает владельца. Проверьте аккаунт вручную перед созданием нового поста.
Явные отказы дают `failed`. На сайте используются постоянные ID заметок.
Прерванные изменения в Git-копии требуют проверки; бот их не сбрасывает.
Пока одна отправка ждёт появления фото на сайте, последующие ждут в очереди.
Ожидание сайта ограничено 30 минутами; обработка контейнера Instagram — часом.

При ошибке не обещается автоматический повтор. После проверки состояния можно
создать новую публикацию через `/publish`. Удаление с одной площадки не удаляет
материал на другой. Для удаления сайта удалите соответствующие JSON/изображение,
пересоберите и опубликуйте сайт; Instagram удаляется отдельно.

Проверки: `python3 -m unittest discover -s telegram_bot/tests -q`,
`python3 scripts/build.py`, `python3 scripts/check.py`. Тесты используют заглушки
внешних API и локальный Git-репозиторий; они не подтверждают живую Meta-публикацию.
