# Trofim Mini App

Мини-приложение Telegram показывает услуги, стоимость и контакты Трофима Мокрова. Данные берутся из `content/services.json` и `content/site.json`. Команда `python3 scripts/build.py` обновляет `miniapp/catalog.json`.

## Как посетитель открывает приложение

В личном чате с `@TrofimAI_bot` отправьте `/menu` и нажмите **«Открыть приложение»** на клавиатуре бота. Кнопка появляется, когда процесс запущен с `TELEGRAM_MINIAPP_URL=https://trofimmokrov-netizen.github.io/TrofimMokrov/miniapp/`.

## Путь заявки

Кнопки заявки в карточках услуг, блоке пробной задачи, меню и контактах открывают форму Битрикс24 по адресу `<base_url>/contact.html#request-form`. В Telegram приложение вызывает `Telegram.WebApp.openLink`. В обычном браузере и в старых версиях клиента работает стандартная ссылка. Если каталог недоступен, открывается форма на сайте, где размещено приложение.

Посетитель заполняет форму на сайте. Название услуги и формат заявки автоматически не подставляются. Если посетитель хочет начать с пробной задачи, формат можно уточнить при обсуждении. Способ ответа и уведомления определяют настройки Битрикс24. Сервер бота сохраняет совместимость с данными заявок от предыдущих версий мини-приложения.

## Проверки

Из корня репозитория при работающем локальном сервере на порту 8011:

```sh
python3 scripts/build.py
python3 -m unittest discover -s telegram_bot/tests -v
CHROMIUM_PATH=/usr/bin/chromium SITE_URL=http://127.0.0.1:8011 node scripts/miniapp-check.cjs
```

Браузерная проверка использует имитацию Telegram SDK. Она проверяет светлую и тёмную темы, ширины 320/390/768 px, каталог, контакты, кнопки перехода к форме и резервные ссылки. Тестовые заявки в Битрикс24 не отправляются.
