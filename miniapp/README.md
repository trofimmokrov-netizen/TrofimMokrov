# Trofim Mini App

Статическое мини-приложение Telegram: девять направлений из общего каталога сайта, цены, состав услуги, контакты и форма с проверкой перед отправкой. Данные берутся из `content/services.json` и `content/site.json`; `python3 scripts/build.py` обновляет `miniapp/catalog.json`. Секретов в клиентском коде нет.

## Как посетитель открывает приложение

В личном чате с `@TrofimAI_bot` отправьте `/menu` и нажмите **«Открыть приложение»** на клавиатуре бота. Кнопка появляется, когда процесс запущен с `TELEGRAM_MINIAPP_URL=https://trofimmokrov-netizen.github.io/TrofimMokrov/miniapp/`. Сначала опубликуйте файлы по этому адресу и проверьте HTTPS-загрузку HTML, JS, CSS и JSON, затем включайте кнопку.

Используется **KeyboardButton.web_app**, а не кнопка меню профиля или inline-кнопка. Это важно: `Telegram.WebApp.sendData` передаёт данные в бот для запуска через клавиатуру. Не меняйте тип запуска на `setChatMenuButton` без отдельной реализации серверного API с проверкой `initData`.

В обычном браузере каталог доступен для просмотра, а отправка отключена: предлагается открыть бот и его кнопку приложения. Открытие страницы в браузере само по себе не превращает её в авторизованный Telegram-сеанс.

## Путь заявки

1. Посетитель выбирает услугу, пишет задачу и контакт, отмечает согласие на передачу Трофиму.
2. Приложение показывает проверочный экран. До нажатия «Отправить заявку» данные не передаются.
3. `sendData` передаёт JSON в Telegram, и приложение закрывается. Telegram доставляет боту служебное сообщение `web_app_data`.
4. Бот проверяет тип, версию, согласие, идентификатор услуги, длины и размер JSON, затем использует общую транзакцию сохранения и уведомления. Личность берётся только из `message.from`; клиентские `chat_id`, `source`, `price` и получатели не используются.
5. Посетитель получает номер в чате, владелец — уведомление. Повтор одного `update_id` не создаёт новую заявку. Ограничение — три заявки на чат за сутки.

Цена показана для ориентира и не является суммой платежа. Оплата не реализована. Черновик хранится только в памяти открытой страницы, без localStorage и без отправки по мере ввода. Поле описания — 10–1500 символов, контакт — 5–160, суммарный JSON — до 4096 байт.

Бот также показывает сайт, раздел «Обо мне», портфолио и контакты, а помощник отвечает на типовые вопросы по текущему каталогу. Это помощник по материалам сайта; произвольная генерация ответов внешней языковой моделью и интеграция Notion пока не подключены.

## Проверки

Из корня репозитория при работающем локальном сервере на порту 8011:

```sh
python3 scripts/build.py
python3 -m unittest discover -s telegram_bot/tests -v
CHROMIUM_PATH=/usr/bin/chromium SITE_URL=http://127.0.0.1:8011 node scripts/miniapp-check.cjs
```

Браузерная проверка подменяет только Telegram SDK, не отправляет настоящие заявки и не подтверждает доставку из реального клиента Telegram. Она проверяет обе темы, ширины 320/390/768, каталог, выбор услуги, согласие, просмотр и изменение, единственный вызов `sendData`, просмотр вне Telegram и отказ каталога.

После публикации откройте приложение из клавиатуры настоящего бота и отправьте тестовую заявку. Проверьте совпадение номера, данных в базе и уведомления владельцу. Для получения заявок процесс бота должен продолжать работать с постоянным диском. Публикация статического Mini App не обеспечивает постоянную работу этого процесса.
