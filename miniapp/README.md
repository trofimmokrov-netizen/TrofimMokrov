# Trofim Mini App

Мини-приложение Telegram показывает услуги, цены, контакты и форму заявки. Данные каталога берутся из `content/services.json` и `content/site.json`. Команда `python3 scripts/build.py` обновляет `miniapp/catalog.json`.

## Как открыть приложение

В личном чате с `@TrofimAI_bot` отправьте `/menu` и нажмите **«Открыть приложение»** на клавиатуре бота. Кнопка появляется, когда процесс запущен с `TELEGRAM_MINIAPP_URL=https://trofimmokrov-netizen.github.io/TrofimMokrov/miniapp/`.

## Заявка и чат

С главной можно перейти к каталогу услуг, портфолио, контактам или заявке. На вкладке «Контакты» доступны личный Telegram, электронная почта и профили Instagram и ВКонтакте с именем `trofimmokrov`. В Telegram социальные профили открываются через возможности клиента. В браузере работают обычные ссылки.

Кнопка заявки на главной, вкладка «Заявка», карточки услуг и блок пробной задачи открывают форму Битрикс24 внутри мини-приложения. Используется та же форма, что на сайте. Она загружается при первом открытии вкладки. Выбранная услуга отображается над формой, а передача полей и обработка заявки определяются настройками Битрикс24.

На всех вкладках доступен виджет Битрикс24 с сайта. Каналы и доступность чата задаются в Битрикс24. Если форма не загрузилась, можно открыть контакты прямо из вкладки заявки.

## Проверки

Из корня репозитория при работающем локальном сервере на порту 8011:

```sh
python3 scripts/build.py
python3 -m unittest discover -s telegram_bot/tests -v
CHROMIUM_PATH=/usr/bin/chromium SITE_URL=http://127.0.0.1:8011 node scripts/miniapp-check.cjs
```

Браузерная проверка использует имитации Telegram SDK и загрузчиков Битрикс24. Она проверяет переходы с главной, прямые контакты, открытие социальных профилей через Telegram и в обычном браузере, загрузку встроенной формы, сохранение введённых данных при переключении вкладок, размещение виджета над нижней панелью и действия при недоступном каталоге или форме.
