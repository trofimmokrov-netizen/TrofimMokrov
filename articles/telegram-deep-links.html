Как работают ссылки запуска в Telegram

Разбираем параметры start и startapp, понятные запуски из карточек и запасной маршрут при старой ссылке.

В этой статье
  1. Передавайте короткий код назначения
  2. Согласуйте подпись и экран назначения
  3. Различайте ссылки бота и мини-приложения
  4. Проверьте ссылку в нескольких ситуациях

Передавайте короткий код назначения

Ссылка вида t.me/BOT_USERNAME?start=repair ведёт к боту и передаёт ему параметр запуска repair. Замените BOT_USERNAME именем своего бота. После запуска обработчик получает команду /start с этим параметром и может открыть карточку ремонта. Для start Telegram допускает латинские буквы, цифры, дефис и подчёркивание. Укладывайте код в 64 символа. Подходящая структура для каталога получается из коротких постоянных названий услуг.

Согласуйте подпись и экран назначения

Разместите на сайте ссылку рядом с услугой, которую она открывает. Если кнопка подписана «Записаться на диагностику», бот должен показать выбранное направление и объяснить дальнейший шаг. Переход по ссылке сам по себе может служить входом в диалог. Для отправки заявки пригодится отдельное подтверждение. Если услугу переименовали, сохраните поддержку старого кода или покажите понятное предложение открыть текущий каталог.

Различайте ссылки бота и мини-приложения

Параметр start относится к запуску диалога с ботом. Прямая ссылка для настроенного мини-приложения может выглядеть как t.me/BOT_USERNAME/APP_SHORT_NAME?startapp=repair. Здесь APP_SHORT_NAME заменяется коротким именем приложения. Такой переход открывает интерфейс приложения, где код можно использовать для выбора экрана. Перед публикацией проверьте режим запуска, поскольку от него зависят доступные возможности Telegram, в том числе способы передачи данных боту.

Проверьте ссылку в нескольких ситуациях

Откройте её из браузера телефона и из сообщения Telegram. Повторите проверку в новом чате и в чате с открытым меню. Затем передайте неизвестный код и посмотрите, останется ли доступ к услугам и контактам. Идентификатор запуска может быть виден в истории браузера, аналитике и пересланной ссылке. Для этого параметра подходят только данные, которыми можно безопасно поделиться.
