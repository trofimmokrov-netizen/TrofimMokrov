Как настроить пути на GitHub Pages для сайта проекта

Почему у сайта GitHub Pages пропадают стили на вложенных страницах, когда задавать базовый путь и что можно разместить на статическом хостинге.

В этой статье
  1. Найдите адрес, с которого реально открывается сайт
  2. Выберите способ построения путей
  3. Проверьте результат по глубокому адресу
  4. Оставьте на Pages то, что выполняется статически

Найдите адрес, с которого реально открывается сайт

Сайт проекта на стандартном домене GitHub Pages обычно открывается под именем репозитория. Например, у сайта user.github.io/portfolio/ путь /assets/styles.css указывает на общий корень домена, а файл проекта доступен под /portfolio/assets/styles.css. Сайт отдельного пользователя или сайт на собственном домене может открываться уже с корня. Запишите ожидаемый адрес публикации, включая подкаталог, и проверьте, откуда браузер загружает файл на главной и во вложенной статье.

Выберите способ построения путей

В небольшом наборе HTML удобно использовать пути относительно страницы. Для главной можно указать assets/styles.css, а на странице в папке articles подняться на уровень выше. При нескольких уровнях вложенности поручите генератору вычислять эти ссылки. Если проект собирается инструментом с параметром базового адреса, задайте ему опубликованный префикс и проверьте результат сборки. Отдельно проверьте адреса внутри CSS и JavaScript, иконки, навигацию, canonical и ссылки в sitemap. У каждого URL свой источник, поэтому правка одного шаблона может закрыть только часть ошибок.

Проверьте результат по глубокому адресу

Откройте статью по сохранённой прямой ссылке в новой вкладке. Обновите страницу и посмотрите во вкладке сети запросы к шрифту, стилям, сценариям и изображениям. Любой ответ с ошибкой разберите по конечному URL и имени файла в публикации, включая регистр букв. Повторите проверку после изменения имени репозитория или домена. Если интерфейс использует маршруты на стороне браузера, отдельно испытайте обновление вложенного адреса. Серверу Pages для прямого открытия нужен соответствующий опубликованный файл, либо приложению потребуется другая схема маршрутов.

Оставьте на Pages то, что выполняется статически

GitHub Pages раздаёт подготовленные HTML, CSS, JavaScript и медиа. Для обработки формы с закрытым ключом, записи в базу и фоновой очереди требуется внешний управляемый сервис или отдельная серверная часть. Перечислите такие зависимости до выбора хостинга и проверьте условия использования Pages для своего проекта. При внешней форме испытайте загрузку и подтверждение отправки с опубликованного домена.
